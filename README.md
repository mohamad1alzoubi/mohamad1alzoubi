## Featured Research Artifact

### Coded Evidence Base for FL-NIDS Reporting Fragmentation

A PRISMA-oriented systematic literature review of **105 primary studies** on federated learning-based network intrusion detection systems. Each study was coded with a structured framework covering architecture, datasets, an adversarial-evaluation proxy, and explainability coverage.

Within the reviewed corpus, 9 of 105 studies had non-unknown values across all four coded dimensions. This provides quantitative evidence of cross-dimensional reporting fragmentation within the reviewed literature.
